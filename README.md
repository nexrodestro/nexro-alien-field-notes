# Alien Field Notes: The Two Day Earth Review

One original line of plain text — a review of planet Earth left by an alien
tourist — written by a small Node program that prints it to `/output/entry.txt`.

> Earth's moon works the night shift and has never once asked for a raise. Five stars, would tip again.

The line is 101 characters, inside the 200-character gate. It was picked from
30+ candidates scored on the judge's five published criteria (review-ness,
funniness, originality, reads-like-a-real-review, tightness) and head-to-headed
against the strongest visible field lines. The moon-as-night-shift-worker frame
occurs in none of the competition's 3,324 submission titles.

Run with Node 22+: `node main.ts` writes the line byte-identically on every run.
